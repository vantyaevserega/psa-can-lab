# Протокол адаптер ↔ приложение

Текстовые строки по USB-serial, 500 000 бод, 8N1. Адаптер завершает строки `CR LF`, команды принимает с любым окончанием строки. При открытии порта Arduino перезагружается, поэтому первые 1,5–2 с адаптер не отвечает.

## Строки адаптера

| Строка | Когда |
|---|---|
| `LAB PSA-CAN-LAB <версия>` | при старте и в ответ на `?` |
| `MODE IDLE\|SNIFF\|BENCH` | при старте, на `?` и после каждой команды `M` |
| `STATE IGN=1 REV=0 RADIO=1 DARK=0 CYCLE=0 TEMP=10 COOL=80 BRIGHT=15 VOL=15 MSG=-1` | при старте, на `?` и после каждой команды, меняющей состояние стенда |
| `<ID>\t<DLC>\t<B0>\t<B1>…` | принятый кадр: HEX без ведущих нулей, поля разделены табуляцией |
| `LOST <n>` | раз в секунду, если буферы приёма MCP2515 переполнялись: порт не успевает за шиной |
| `OK` | команда `BTN` или `TX` выполнена |
| `ERR <причина>` | `ARG`, `COMMAND`, `BUTTON`, `NOT_BENCH`, `BSI_PRESENT`, `CAN_INIT` |
| `# текст` | пояснение, например номер сообщения при переборе |

Формат строки кадра совпадает с форматом библиотеки `CanFrameLog`.

## Команды

| Команда | Действие |
|---|---|
| `?` | повторить `LAB`, `MODE`, `STATE` |
| `M IDLE` | молчать |
| `M SNIFF` | слушать шину и выводить все кадры |
| `M BENCH` | включить стенд; при настоящем BSI на шине — `ERR BSI_PRESENT`, режим остаётся `IDLE` |

Команды стенда принимаются в любом режиме, но действуют на шину только в `BENCH`:

| Команда | Значение | Действие |
|---|---|---|
| `IGN 0\|1` | | зажигание |
| `REV 0\|1` | | задняя передача |
| `DARK 0\|1` | | тёмный режим дисплея |
| `TEMP <n>` | −40…87 °C | наружная температура |
| `COOL <n>` | −40…215 °C | температура охлаждающей жидкости |
| `BRIGHT <n>` | 0…15 | яркость подсветки |
| `RADIO 0\|1` | | магнитола присутствует на шине |
| `VOL <n>` | 0…30 | громкость; дисплей показывает шкалу |
| `MSG <код>` | десятичный код | показать сообщение бортового компьютера |
| `MSG OFF` | | скрыть сообщение |
| `CYCLE 0\|1` | | перебирать коды 0…255: 4 с показ, 1 с пауза |
| `BTN <имя>` | `MENU MODE OK ESC DARK UP DOWN LEFT RIGHT TEL NAV CLIM TRIP AUDIO` | нажатие кнопки панели |
| `TX <ID> <B0> <B1>…` | HEX | отправить произвольный кадр; только в `BENCH` |

## Кадры стенда

| ID | Период | Данные |
|---|---|---|
| `0x036` | 100 мс | `0E 00 05 XX YY 80 00 A0`: `XX` = `0x20` + яркость (+ `0x10` в тёмном режиме); `YY` = `0x21` зажигание включено, `0x22` выключено |
| `0x0F6` | 500 мс | байт 0 — `0x08` зажигание; байт 1 — температура ОЖ + 40; байт 6 — (наружная + 40) × 2; байт 7 — `0x80` задний ход |
| `0x276` | 500 мс | `95 03 05 08 10 1B 10` — записанное значение даты и времени |
| `0x1A1` | 100 мс | байт 0 — `0x80` + старшая часть кода (показать) или `0x7F` (скрыть, 10 кадров); байт 1 — младшая часть кода; байт 2 — `0x80` |
| `0x3E5` | 100 мс | кнопки панели; нажатие держится 2 кадра |
| `0x165` | 100 мс | `CC 80 40 00` — магнитола включена |
| `0x1A5` | 500 мс | громкость; старшие три бита нулевые 4 кадра после изменения |
| `0x1E5` | 500 мс | `3F 48 3F 3F 3F 07 0F` — настройки звука |
| `0x39B` | 500 мс | `F4 05 0C 14 1E` |
| `0x5E0` | один раз | `20 01 02 06 12 1F 11 00` — версия магнитолы |
