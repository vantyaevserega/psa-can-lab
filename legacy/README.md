# Исходники прежних проектов

Здесь сохранены без изменений исходники трёх репозиториев, которые заменил этот проект. Они не собираются вместе с ним и оставлены для истории.

| Папка | Что это было | Чем заменено |
|---|---|---|
| `CanFrameLog/` | библиотека вывода кадра в `Serial` | функция `printFrame` в прошивке; формат строки сохранён |
| `EmulateBSIPSA/` | библиотека эмуляции BSI для штатного дисплея | режим стенда в прошивке |
| `TestPSAScreen/` | скетч стенда штатного дисплея | режим стенда и пульт в приложении |
